Run Locally
No build step is needed to preview the static portfolio.
1. Download or clone the repository.
2. Open the project folder in VS Code.
3. Install the Live Server extension.
4. Right-click index.html and choose Open with Live Server.
Use a local HTTP server rather than opening index.html with file://, because the site loads JavaScript ES modules.

Deployment
The static website can be deployed to Netlify or Cloudflare Pages.
- Build command: none
- Publish directory: repository root (.)
- Entry point: index.html
If your hosting workflow detects package.json and attempts a Vite build, configure it to publish the static root site rather than the unrelated experimental app.

Before going live, update the placeholder canonical URL in index.html, confirm the final images and metadata, and test navigation and contact links on the deployed domain.
